# textbook-tw 架構

## 目標

- 翻譯英文 PDF 簡報與教科書為台灣繁體中文
- 保留原版面、圖片、圖表、公式
- 輸出純譯文版，以及使用者可選的中英對照版（左右並排、交替頁、兩種都要）
- 全部在本機執行，使用本地模型
- 主要領域：工程數學、航太、流體力學，專有名詞要正確且全書一致

## 目標硬體

開發機：RTX 2060 6GB、16GB 記憶體。模型以 4B～9B 為主，模型檔放 D 槽（設定 `OLLAMA_MODELS`）。

## 元件

```
使用者：拖放 PDF、選科目、選輸出格式
        │
        ▼
┌─ 網頁介面（Gradio）／指令列 ──────────────┐
│  任務管理：排隊、進度、中斷後接著翻         │
└────┬───────────────────────────┬─────────┘
     ▼                           ▼
 術語系統                    版面引擎 BabelDOC（鎖定版本）
 名詞庫下載 → 清理            解析版面、辨識圖表與公式、
 → 依科目合併 → 掃描 PDF ───► 填回譯文、輸出純譯文 PDF
 → 文件專屬術語表                  │ 一段一段送出
                                   ▼
                        翻譯閘道（OpenAI 相容）
                        關閉思考模式、簡轉繁、
                        大陸用語檢查、紀錄每段譯文
                                   │
                                   ▼
                        Ollama（本地模型）

 對照版組版：原文 PDF + 純譯文 PDF → 左右並排版／交替頁版
```

| 模組 | 位置 | 職責 |
|---|---|---|
| 版面引擎 | `src/textbook_tw/engine/` | 唯一直接呼叫 BabelDOC 的地方。BabelDOC 官方表示其 API 皆屬內部 API，因此鎖定版本並集中在此，升級時只改這裡 |
| 術語系統 | `src/textbook_tw/glossary/` | `fetch` 下載國教院名詞庫、`naer` 解析與清理、`lexicon` 依科目合併、`book` 掃描 PDF 產生文件專屬術語表 |
| 翻譯閘道 | `src/textbook_tw/gateway/` | BabelDOC 與 Ollama 之間的小型服務，處理模型差異與譯文品質 |
| 後處理 | `src/textbook_tw/postprocess/` | OpenCC 簡轉繁（台灣用語）、全形標點、大陸用語檢查 |
| 對照版組版 | `src/textbook_tw/compose/` | 用原文與純譯文 PDF 組出對照版 |

### 為什麼對照版自己組

BabelDOC 每次只能輸出一種對照格式。純譯文版的頁面與原文一對一，所以只讓 BabelDOC 輸出純譯文版，再用 PyMuPDF 自己組出左右並排版和交替頁版。好處是兩種格式只需翻譯一次，版面細節（頁面間距、標示）也能自己控制。

### 為什麼要翻譯閘道

- 小模型常冒出簡體字與大陸用語，需要統一修正
- ~~Qwen3.5 的思考模式會浪費時間，需要關閉~~（第 1 階段已用 BabelDOC 的 `reasoning` 參數解決，不需要閘道）
- 不同模型需要不同的提示格式（例如翻譯專用的 HY-MT），差異集中在這一層處理
- 記錄每段原文與譯文，方便事後找出翻錯的地方

## 術語策略

1. **來源**：國家教育研究院學術名詞 CSV（清單見 `glossary/sources.toml`，第一次使用時自動下載到 `glossary/raw/`），之後可加 Wikidata（CC0）補充較新的詞
2. **清理**（`naer.py`）：
   - 中文欄以「；」「;」「，」「、」拆成多個譯名，第一個是首選
   - 刪除領域標記 `[天]`、`【物】`、`{螺槳}`、`｛數學｝`
   - 中文括號：詞尾兩字以上是註解，刪除（房室阻滯（心電圖））；其他是可省略的字，保留（加速（度）梯度 → 加速度梯度）
   - 英文倒裝還原（acceleration; gravitational → gravitational acceleration），刪除英文括號（縮寫）；含 `/`、`,` 的寫法無法判斷，略過
3. **科目優先順序**（`lexicon.py`）：`config/profiles/*.toml` 的 `glossaries` 決定名詞庫的優先順序，解決跨科目的譯名衝突
4. **文件專屬術語表**（`book.py`）：掃描 PDF 全文，只挑出真的出現的詞（含最後一個字的複數形）
   - 多字詞組：都收（整組都是 less、than 這類功能字的除外）
   - 單一單字：名詞庫裡大多是一般用字（can→罐、over→請回答、figure→數字），所以只看英文詞頻 Zipf < 3.6 的少見字（wordfreq），且至少兩個名詞庫首選譯名一致才收；不一致而且出現 3 次以上的列為「待確認」
   - **必要性**：BabelDOC 用不分大小寫的子字串比對術語、不看單字邊界，若放入整個名詞庫，短字會誤中（lift 會比對到 uplift）
5. **使用者確認**：術語表存成 `glossary/books/<檔名>.csv`（UTF-8 BOM，Excel 可直接開），使用者改 `target` 欄、清空代表不用；之後翻譯同一份 PDF 都沿用，`glossary scan --force` 才會覆蓋
6. **個人修正**：`glossary/my_terms.csv` 優先權最高，每次翻譯時才合併，所以修改後不用重新掃描
7. 關閉 BabelDOC 內建的自動術語抽取（`--no-auto-extract-glossary`），因為它會讓本地模型多跑一輪，時間約翻倍

## 模型評比

從實際教材抽 30～50 段（只存在本機 `eval/samples/`），比較候選模型：

| 指標 | 說明 |
|---|---|
| 術語命中率 | 術語表中的詞是否照指定譯名翻譯 |
| 公式符號保留 | BabelDOC 用來代表公式的符號是否完整保留 |
| 簡體字／大陸用語 | 後處理前的出現次數 |
| 速度 | 每頁平均秒數 |

候選模型：Qwen3.5-4B（預設）、Qwen3.5-9B、騰訊 HY-MT1.5-7B／Hy-MT2-1.8B。

### 實測紀錄

**2026-10-26，Qwen3.5-4B，Ollama 0.40.11，RTX 2060 6GB**，翻譯一段約 100 字的流體力學英文：

| 呼叫方式 | 時間 | 輸出 token |
|---|---|---|
| 原生 API，`think: false` | 1.7 秒 | 114（約 75 token/秒） |
| OpenAI 相容 API，不加參數 | 33.9 秒 | 2495（大部分是思考內容） |
| OpenAI 相容 API，`reasoning_effort: "none"` | 1.6 秒 | 109 |

- 模型 2.9 GiB，100% 在顯卡上執行
- **BabelDOC 走 OpenAI 相容 API，預設會開思考模式，慢 20 倍**，所以必須關閉思考模式（第 1 階段確認 BabelDOC 的 `reasoning` 參數可以做到，見下方）
- 沒有出現簡體字，但出現大陸用語：「無量綱」（應為「無因次」）、「湍流」（應為「紊流」）、airfoil 譯成「機翼」（應為「翼型」）。證實需要術語表與大陸用語檢查
- 粗估速度：每頁約 10 秒，一本 500 頁教科書約 1.5～3 小時（含版面分析）

**2026-10-26，第 1 階段，BabelDOC 0.6.4 + Qwen3.5-4B**

| 文件 | 頁數 | 時間 |
|---|---|---|
| 空氣動力學講義（PowerPoint 匯出，橫向） | 26 | 3 分 13 秒 |
| *Aerodynamics for Engineers* 第 8 章前 8 頁 | 8 | 2 分 10 秒（約每頁 16 秒） |

發現與對應做法：

| 現象 | 原因 | 做法 |
|---|---|---|
| BabelDOC 的 `--openai-thinking disabled` 無效 | Ollama 不認得 DeepSeek 格式 | 改用 `reasoning="none"`（送出 `reasoning: {effort: "none"}`），實測有效 |
| 頁首 "Feng Chia University" 被譯成「國立清華大學」「國立成功大學」 | 模型照指示保留英文後，BabelDOC 判定「譯文與原文相同」改用簡單指令重翻，小模型在那一步亂編名稱 | 指令要求機構名稱保留原文，並開啟 `disable_same_text_fallback` |
| 投影片譯文變成明體，原文是粗黑體 | BabelDOC 自動判斷字型 | 設定 `font = "auto"`：橫向頁面（投影片）用黑體 |
| 投影片同一個文字框裡的條列項目（L=、D=、M=）被合併成一段 | BabelDOC 依文字框判斷段落；`split_short_lines` 試過沒有效果 | 暫不處理，可讀性尚可 |
| 投影片的 u∞、α 等符號蓋在中文字上 | PowerPoint 把符號存成獨立定位的文字，BabelDOC 沒辨識為行內公式 | 已知限制；教科書（LaTeX／出版社排版）沒有這個問題 |
| 教科書表格裡的 `0 < M < 1` 變成 `0 6 M 6 1` | 出版社數學字型（PearsonMATH）用自訂編碼，BabelDOC 重新排版時換了字型 | 待查：表格內的數學符號應保留原字型或不重排 |
| 約 2% 段落（120 頁中 28 段）改用簡單指令重翻 | 模型回傳的 JSON 格式不符，BabelDOC 逐段重翻；這一步不帶自訂指令與術語表 | 第 3 階段由翻譯閘道記錄並檢查 |
| 人名機構名偶爾仍被翻譯（Sandia National Laboratories → 沙國國家實驗室） | 4B 模型不一定遵守指令 | 術語表加入常見機構名；評比更大的模型 |

整本 *Aerodynamics for Engineers* 第 8～9 章（120 頁）：**25 分 32 秒**（約每頁 13 秒）。

**2026-10-26，第 2 階段，術語表**

掃描 *Aerodynamics for Engineers* 第 8～9 章（約 4 萬字）只要約 3 秒；合併 9 個名詞庫約 2 秒。

| 版本 | 術語數 | 待確認 | 備註 |
|---|---|---|---|
| 單字只看長度（≥ 7 字母） | 1061 | 155 | 待確認大多是一般用字（equation、surface、process） |
| 加上英文詞頻篩選（Zipf < 3.6） | 851 | 40 | 待確認都是專業術語（airfoil、stagnation、isentropic、hypersonic） |

科目設定影響很大：「流體力學」與「航太」兩種設定在 816 個共同術語中有 85 個譯名不同，例如：

| 英文 | 流體力學（力學優先） | 航太（航空太空優先） |
|---|---|---|
| drag coefficient | 曳力係數 | 阻力係數 |
| turbulent boundary layer | 亂流邊界層 | 紊流邊界層 |
| perfect gas | 完全氣體 | 理想氣體 |
| inviscid flow | 無黏滯流 | 非黏性流 |
| control volume | 控制體 | 控制體積 |

用「航太」術語表翻譯前 8 頁，與沒有術語表時比較：

| 英文 | 沒有術語表 | 有術語表 |
|---|---|---|
| chain rule | 鏈式法則 | 鏈鎖法則、連鎖律 |
| shock wave | 激波 4、衝擊波 4 | 震波 4、激波 4 |
| perfect gas | 完美氣體 14 | 完全氣體 4（熱完全氣體）、完美氣體 2 |

- 時間從 2 分 10 秒增為 2 分 54 秒（指令變長）
- 4B 模型不一定照術語表翻；殘留的「激波」來自單獨出現的 shock（常用字，術語表沒收），可加進 `my_terms.csv` 或由第 3 階段的大陸用語替換處理
| 相依套件太新導致 BabelDOC 無法啟動（bitstring 5） | BabelDOC 只設版本下限 | `tool.uv.exclude-newer` 鎖在 BabelDOC 發布當時 |
| 大陸用語：伯努利（白努利）、鏈式法則（連鎖律）、迎角（攻角）、縮放噴嘴（漸縮漸擴噴嘴） | 小模型的訓練資料以大陸用語為主 | 第 2 階段術語表 |

Ollama 紀錄中沒有任何請求被截斷；BabelDOC 單次請求最多約 1100 個 token，遠低於預設的 4096 上下文。
